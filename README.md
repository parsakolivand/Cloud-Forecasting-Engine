# Cloud Forecasting Engine

An open forecasting engine for FinOps engineers. Connect your cloud provider and get a cost forecast for the next 12 months.

## Vision

FinOps teams around the world spend a lot of time building one-off spreadsheets and scripts to predict cloud spend. Cloud Forecasting Engine aims to be a single place where you can:

- **Connect** your cloud billing data (e.g. AWS, Azure, GCP)
- **Forecast** spend for the next 12 months
- **Understand** what drives the forecast, by service, account and team
